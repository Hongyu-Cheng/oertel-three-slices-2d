## Statement

Use the system family \(\mathcal S_{\eta,\tau_Q,\tau_R,\sigma}\) of accepted fact `b046e3066136e781`, with the reduced word list and counts of accepted fact `46afc7eb815ffc5b`.

For every \(\eta\in\{0,1,2\}\) and every allowed label vector
\[
\sigma_P\in\mathcal A,\qquad
\sigma_Q,\sigma_R\in\mathcal B,
\]
the system
\[
\mathcal S_{\eta,\mathrm F,\mathrm F,\sigma}
\]
is infeasible.

## Proof

Fix such a system and suppose it is feasible. By the full-tail equations in accepted fact `b046e3066136e781`,
\[
b=m,\qquad d=k.
\]
The same system contains
\[
9t=2(1+m+k),\qquad
\Omega=2t-b-d,\qquad
\Omega\ge0.
\]
Consequently,
\[
0\le\Omega
=2t-m-k
=\frac{4(1+m+k)-9(m+k)}9
=\frac{4-5(m+k)}9,
\]
so
\[
m+k\le\frac45. \tag{1}
\]

On the other hand, every residual-strip branch forces \(m+k>1\). Indeed, \(m=q^2\). If \(\eta=0\), then
\[
k>1-q^2,
\]
hence
\[
m+k=q^2+k>1.
\]
If \(\eta=1\) or \(\eta=2\), then
\[
5q>3,\qquad
2k>3q^2+2q-1.
\]
Since \(q>0\),
\[
\begin{aligned}
2(m+k)
&=2q^2+2k\\
&>5q^2+2q-1\\
&=2+(5q-3)(q+1)\\
&>2.
\end{aligned}
\]
Thus \(m+k>1\) in these branches as well, contradicting (1).

The contradiction uses no condition on \(\sigma\), so it eliminates every full/full word class. Accepted fact `46afc7eb815ffc5b` counts \(34928\) such classes for each of the three values of \(\eta\). Therefore exactly
\[
3\cdot34928=104784
\]
systems are removed.
